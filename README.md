# nixpkg-pdfcraft

Nix package for [ArtCraft PDFcraft](https://github.com/storytold/pdfcraft), using its official Linux x86_64 release archive. The package installs the app directly; it does not include the ArtCraft launcher or provide an auto-updater.

Pinned upstream release: `v0.13.0`.

```sh
nix build
nix run
```
